
# AWS Databases — Amazon RDS MySQL & DynamoDB

## Overview

This project demonstrates the deployment and management
of relational and NoSQL databases on AWS using
Infrastructure as Code (IaC) with Terraform.

The infrastructure is deployed in the AWS Spain Region
(`eu-south-2`).

## Objectives

- Deploy an Amazon RDS MySQL instance using Terraform.
- Create an Amazon DynamoDB table.
- Load the same customer and order data into both databases.
- Execute SQL queries, including JOIN and GROUP BY.
- Execute GetItem, Query and Scan operations in DynamoDB.
- Create, verify and delete a manual RDS snapshot.
- Destroy all infrastructure and verify resource cleanup.
- Compare relational and NoSQL database models.
